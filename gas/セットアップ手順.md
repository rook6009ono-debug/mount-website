# マウントHP × Equal Web 接続セットアップ手順

マウントのホームページを「管理画面から更新できる」状態にするための手順です。
所要時間は15〜20分ほど。Googleアカウントがあれば完了します。

このフォルダの3ファイルを使います:
- `コード.gs` — Equal Web本体（v3.3・会社概要 追加項目対応）
- `index.html` — 管理画面
- `seed-mount.gs` — マウントの初期データ投入

---

## 1. データベース（スプレッドシート）を作る

1. Googleドライブで **新しいスプレッドシート** を作成
2. 名前を **「マウントHP_DB」** に変更

## 2. プログラムを貼り付ける

1. スプレッドシートのメニュー **拡張機能 → Apps Script** を開く
2. 最初からある `コード.gs` の中身を全部消して、このフォルダの **コード.gs** の中身を貼り付け
3. 左の「＋」→ **HTML** → ファイル名 `index` で作成し、**index.html** の中身を貼り付け
   （最初から入っている `<html>…` は全部消してから貼る）
4. 左の「＋」→ **スクリプト** → ファイル名 `seed` で作成し、**seed-mount.gs** の中身を貼り付け
5. 💾 保存（Ctrl+S）。プロジェクト名は「マウントHP管理」などに変更

## 3. 初期セットアップを実行する

1. 上部の関数選択で **initialSetup** を選び「実行」
   - 初回は承認ダイアログ → 自分のアカウント → 「詳細」→「（安全ではないページ）に移動」→ 許可
   - → company_master など **5つのシート** が自動生成される
2. 続けて関数 **seedMount** を選び「実行」
   - → マウントの会社情報・会社概要 追加項目（建設業許可・沿革など）・お知らせ1件が入る
3. 続けて関数 **enablePublicMode** を選び「実行」
   - → 実行ログに **管理画面キー**（例: `a1b2c3…`）が表示されるのでメモする

## 4. 公開する（デプロイ）

1. 右上 **デプロイ → 新しいデプロイ**
2. 種類の選択（歯車）→ **ウェブアプリ**
3. 設定:
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
4. 「デプロイ」→ 表示された **ウェブアプリURL（…/exec）** をコピー

これで:
- **管理画面** = `（execのURL）?key=（手順3-3でメモしたキー）`
- **公開API** = `（execのURL）?action=api`

## 5. ホームページと接続する

`mount-website/equalweb-config.js` を開き、apiUrl にexecのURLを貼る:

```js
window.EQUAL_WEB = {
  apiUrl: "https://script.google.com/macros/s/XXXXXXXX/exec"
};
```

→ ホームページのお知らせ・会社概要・お問い合わせ受信が Equal Web と接続されます。

## 6. 動作確認

1. 管理画面（?key=…のURL）を開く → ダッシュボードに「株式会社マウント」と表示される
2. 「会社情報」→ 下の **会社概要 追加項目** に建設業許可などが入っている
3. 試しに従業員数などを変更して保存 → HPの会社概要（about.html）に反映される（最大1分）
4. HPのお問い合わせフォームから送信 → 管理画面「お問い合わせ」に届く

## 管理画面が開けないとき（トラブルシューティング）

**「現在、ファイルを開くことができません」と表示される場合:**
ブラウザに複数のGoogleアカウントがログインしていることが原因です。URLやデプロイは壊れていません。

- **すぐ開きたい** → シークレットウィンドウ（Ctrl+Shift+N）でURLを開く
- **恒久対応（推奨）** → Chromeの「プロファイルを追加」で仕事用プロファイルを作り、使うGoogleアカウント1つだけでログインして、そのプロファイルから開く
- または、すべてのGoogleアカウントをログアウトし、使うアカウントだけでログインし直す

**URLに `/u/1/` などが入っていると404になる:**
`https://script.google.com/macros/u/1/s/…` の形は開けません。`/u/1/` を削除した
`https://script.google.com/macros/s/…/exec?key=…` の形で開いてください。

※お客様に管理画面URLを渡すときも、この2点を一言添えると親切です。

## コード更新の手順（v3.4: 採用情報＝募集要項の管理画面化）

すでにセットアップ済みの環境にコード更新を反映する手順:

1. GASエディタで `コード.gs` と `index` の中身を、このフォルダの最新版で**全文置き換え**て保存
2. 関数 **initialSetup** を実行 → 既存シートはスキップされ、`recruit_settings` シートだけが新規作成される
3. `seed` ファイルも最新版に置き換え、関数 **seedMountRecruit** を実行 → 募集要項12項目が入る
4. **デプロイ → 新しいデプロイ**（これを忘れると反映されない）
   - URLが変わった場合は equalweb-config.js の apiUrl も差し替える
5. 管理画面に「👷 採用情報」メニューが増えていればOK。HPの募集要項がここから編集できる

## 運用メモ（重要）

- **コードを修正したら、毎回「デプロイ → 新しいデプロイ」**を行うこと。
  「デプロイを管理 → 新バージョン」は反映されないことがある（実績あり）。
- スプレッドシートは直接編集しない。**必ず管理画面から**。
- 管理画面URL（keyつき）はお客様と共有する“鍵”なので、むやみに公開しない。
- お問い合わせのメール通知先を変えたい場合: Apps Scriptの
  プロジェクト設定 → スクリプトプロパティに `INQUIRY_NOTIFY_EMAIL` を追加（未設定ならシート所有者宛て）。

## HPが管理画面から更新できる項目

| HP上の場所 | 管理画面の場所 |
|---|---|
| トップの「お知らせ」 | お知らせ（公開/非公開・📌固定・画像・リンク） |
| 会社概要の基本項目（社名/代表/住所/TEL/FAX/設立/資本金/従業員数/事業内容） | 会社情報 |
| 会社概要の追加項目（営業所/建設業許可/保有資格/取引銀行/仕入先/所属団体など） | 会社情報 → 会社概要 追加項目（自由に追加・並べ替え可） |
| フッター・お問い合わせページのTEL/FAX・住所 | 会社情報 |
| フッターのSNSリンク | 会社情報（URL・SNS） |
| お問い合わせフォームの受信 | お問い合わせ（未対応バッジ・状態管理・メール通知） |
