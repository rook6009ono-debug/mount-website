# 動く事業マップ

2026-10-28、ユーザー指定の各工事を一枚のアニメーション付き画像で表し、工事箇所を押すと紹介が開く試作。

2026-10-28：ユーザー了承によりbusiness.htmlを正式な事業内容の入口として採用。各ページのヘッダー・フッターとトップの事業セクションに導線を追加。既存の詳細紹介ページは保持。business-preview.htmlは確認用（noindex）。共通標準の仕様は変更しない。

画像は独自のSVGイラスト。人物、塗装ローラー、洗浄、水面状の防水塗膜、信号、通信、街灯、車の動きをCSSで表現。動画ではないため、対象の建物や設備を直接クリックできる。停止ボタンとOSの動きを減らす設定に対応。紹介ダイアログを開いている間は停止し、閉じると選択前の状態へ戻す。

対象15項目：大規模修繕／共通仮設工事／足場仮設工事／下地補修工事／シーリング工事／洗浄工事／塗装工事／防水工事／金物工事／電気工事／街灯設置／信号機設置／通信／高圧／その他。「仮説」は工事用語の「仮設」として表記。

各項目には固定の識別子を使用する。図中の設備・ラベル・下部の工事名から同じ紹介を開く。キーボードのEnter/Spaceでも操作可能。スマホは画像部分だけ横スクロールし、下部の工事名からも操作できる。

Equal Web標準「文章」へ47枠を追加（ページ見出し・案内文＋15工事×見出し・紹介文・ポイント）。正本は既存MOUNT専用Supabaseのequal_web.text_master。固定slot ID business-{工事ID}-{title/body/points}で参照する。図形・動きはサイト側のデザイン資産、公開文章は管理画面で更新。空欄は初期文へ戻る。ポイントは1行1項目。保存後の再読込または最大1分で反映。紹介文は一般的な工事説明として初期登録し、実際の対応範囲に応じて管理画面で調整できる。

登録は対象site_idを限定し、既存値を上書きしない追加処理で実施。PROVISION_MOUNT_BUSINESS_SLOTSの監査記録を保存。認証・権限・会社境界は変更しない。管理画面から同値保存し、apiSaveTexts監査記録と公開API→紹介表示を確認。

検証：全15項目の紹介タイトル一致、信号機の図形から直接開く操作、PC・スマホ表示を確認。

## 2026-10-28：事業内容・施工事例の統合

ユーザー指定により、紹介ダイアログを廃止し、図の下に15工種の写真・説明・ポイント・関連施工事例を配置。図形／ラベル／工事名から固定ID `#service-{工事ID}` へ移動する。施工事例は既存の公開記事を参照し、データを複製しない。works.htmlは検索条件とアンカーを維持してbusiness.htmlへ転送する。サイト内メニューも統合。

Equal Web「写真」に `business-{工事ID}-photo` の15枠を追加（対象site_id限定、監査履歴あり）。既存写真のある8工種は初期写真を使用し、残り7工種は準備中表示。写真の初期化は初期写真／準備中に戻る。「文章」の既存47枠は継続利用する。

施工事例の追加：Equal Web「記事」でカテゴリ「施工事例」、タグに該当工事名を指定して公開する。複数タグは複数工種へ掲載。固定ID形式 `service:waterproof` 等も対応。旧タグ「仮設工事」「下地・タイル補修工事」「外壁洗浄工事」はそれぞれscaffold/repair/cleanに対応。分類できない記事も同ページ末尾「その他の施工事例」に表示し、失わない。管理画面の見出し変更では識別子・工事タグは変えない。

既存サンプル2件はサンプル表示を維持。サイト全体・共通CMSの構成、認証と会社境界は変更しない。
