# トップページとEqual Webの連携

更新日：2026-10-28

管理入口：https://efp-mount.vercel.app/equal-web
公開HP：https://rook6009ono-debug.github.io/mount-website/

マウント専用Supabaseのequal_webが正本。公開HPはequalweb-config.jsの現行APIを参照する。独自管理画面は追加しない。

## 更新する場所

- 「写真」→「トップ：メイン画像（模型イメージ）」でアップロード。
- 「文章」→「トップ：メイン見出し（改行可）」で大見出しを編集。
- 「文章」→「トップ：理由01〜04」の見出し・説明で4つの理由を編集。
- セクション見出し、英文、画像の説明も「文章」で編集できる。
- 文章は「保存」を押す。HPは再読込または最大1分で反映。
- 空欄・写真の「初期に戻す」はHTMLの初期表示へ戻る。

新規写真枠hero-homeを1件、文章枠hero-headline / hero-eyebrow / hero-caption / hero-caption-en / strengths-heading / strengths-note / strength-1〜4-title / strength-1〜4-bodyを14件追加。既存16写真枠・12文章枠と既存入力値は保持。

初期画像は生成した建築模型イメージ。実際の施工写真ではない。JPEG圧縮版を非公開equal-web-assetsへ登録し、公開参照を確認してAPI配信する。管理画面から画像アップロードと文章の同値保存を実施し、audit_eventsへの保存を確認。

## 接続・修正

公開済みf5e71d9のSupabase接続を維持。APIの画像URL生成を内部リクエストURLから環境設定SUPABASE_URLへ変更し、httpsと/functions/v1/を保持。画像デコードのBufferをnode:bufferから明示importし、Denoでも管理アップロードが動くよう修正。MOUNT API version 6。認証・会社境界・社員共有・契約判定は変更しない。

公開JSはHTMLエスケープ・改行変換を維持。空欄に戻した場合も60秒更新時に初期値へ戻す。PC1280×720で4つの理由の説明末尾まで表示確認。

旧GAS停止・通知メール・管理アプリmainへの統合は従来の別残件。今回の連携完了と全移行完了を混同しない。
